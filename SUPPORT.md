# Support

## Documentation

- Distribution architecture, deployment, and operations: [`docs/`](docs/)
- Coolify deployment: [`docs/coolify.md`](docs/coolify.md)
- Upstream Bifrost documentation: https://docs.getbifrost.ai/

## Issues

Use GitHub Issues for reproducible distribution defects. Include the release
tag, image digest, host architecture, Docker version, and relevant logs with
secrets removed.

## Security

Report vulnerabilities privately through GitHub Security Advisories. See
[`SECURITY.md`](SECURITY.md).

## Upstream features

Provider integrations, gateway APIs, and application behavior are upstream
concerns. This repository ships a verified build and deployment layer; it does
not change upstream semantics.
